## **Project Description**

The **Debt Registry** is a decentralized smart contract system designed to help users record, track, update, and clear debts on the blockchain.  
It eliminates the need for centralized recordkeeping and ensures transparency and immutability by storing debt relationships directly on-chain.

This repository includes the **Solidity contract**, **TypeScript contract utilities**, **React hooks**, and a **sample UI component** for interacting with the deployed contract.

---

## **Features**

### ✅ **Add Debt**
Users can record how much they owe a creditor.  
The system supports multiple creditors per debtor.

### ✅ **Update Debt**
Debtors can change the amount they owe to a creditor.

### ✅ **Clear Debt**
A debtor can reset the debt to zero once it has been paid or settled.

### ✅ **View Debt Between Any Two Parties**
Anyone can query the blockchain to check how much a debtor owes a creditor.

### ✅ **Wallet-Gated UI**
Users must connect a Web3-enabled wallet (MetaMask, etc.) to interact with the system.

### ✅ **Error Handling & Validation**
Frontend includes safe user interaction, loading states, and helpful error messages.

## **How It Solves the Problem**

Debt tracking is often messy, unreliable, and dependent on trust. Traditional methods—notes, spreadsheets, or verbal agreements—can be:

- 💀 Lost  
- 🌀 Manipulated  
- 🤷‍♂️ Disputed  
- ❌ Lacking transparency  

This project addresses that by providing:

### ⭐ **1. Immutable Ledger**
Every debt entry is recorded on the blockchain, ensuring it cannot be altered or deleted without transparency.

### ⭐ **2. Trustless Verification**
Both parties (debtor and creditor) can always verify the debt amount independently.

### ⭐ **3. Multiuser Support**
Any number of users can store debts between any number of participants.

### ⭐ **4. Universal Use Cases**
- Personal borrowing/lending  
- College society/group loan tracking  
- Microfinance and community financial systems  
- DAO or Web3 community payments  
- Business vendor tracking  

### ⭐ **5. Transparent Financial Accountability**
Useful for organizations needing a clear, tamper-proof log of financial interactions.
